# Network Engineer Portfolio

A responsive, dependency-free portfolio website for sharing network engineering capstone projects, achievements, and technical writing. Open `index.html` in a browser to preview it, or publish the repository as a GitHub Pages site.

## Make it yours

- Replace **Your Name** and the sample profile text in `index.html`.
- Update the project case studies, tags, and links with your capstone work and real project details.
- Add your own certifications and achievements in the milestones section.
- Replace the field-note prompts with links to articles, lab notes, or presentations.
- Update the contact email, LinkedIn, and GitHub links in the footer and contact section.
- Edit `styles.css` to adjust colors, typography, or layout.

The project filters, mobile navigation, and current-year footer are powered by the small `script.js` file. Google Fonts are optional; the page falls back to system sans-serif and monospace fonts when fonts.googleapis.com is unavailable.
