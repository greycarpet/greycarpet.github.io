E01 / OCTOBER 12 DISCOVERY

Unencrypted baseline

From the read-only Asterisk discovery report. Legacy peer name omitted. A successful peer state and UDP/5061 listener did not constitute an encrypted trunk.

E02 / OCTOBER 12 TLS PREFLIGHT

Four successful gateway handshakes

Original v4 preflight used CA-chain validation, hostname validation, and SNI without insecure retry. It was a network-level certificate trust test, not a media or application call test.

E03 / LOADED ASTERISK CONFIGURATION

Transport and endpoint policy

Post-test runtime output confirmed an explicit TLS transport and mandatory SDES media policy. It was compared with VICIdial-generated configuration. This proved loaded intent, not a call's negotiated media on its own.

E04 / ANSWERED TEST CHANNEL

Negotiated secure audio

The one-call echo test observed an answered PJSIP channel reporting SRTP = 1, read via CHANNEL(rtp,secure,audio). The operator independently confirmed audible echo and DTMF termination.

E05 / TWILIO CALL RECORD

Independent carrier corroboration

A matching Twilio call export, reviewed October 12, marked the 45-second test call completed with Secure Trunking=true. Its Trunk SID field was null; no explanation for that null field is invented. The local endpoint configuration and matching time/call details supported attribution.

PUBLICATION BOUNDARY

What this register does not establish

The evidence confirms a defined outbound Asterisk-to-Twilio secure trunk path and an answered encrypted test call. It does not establish organization-wide encryption, inbound/agent/inter-server/PSTN protections, complete recording security, renewal/refresh lifecycle, call-capacity sufficiency, exhaustive failover or transfer testing, plaintext-offer rejection, or organizational compliance certification.
